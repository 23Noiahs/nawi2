# nawi2 – NAWI Lernseite

`nawi-lernseite.html` ist eine einzelne, komplett eigenständige interaktive Lernseite (Deutsch) für den NAWI-Test: Ladung & elektrische Kraft, Coulomb, Ladungserhaltung, reibungselektrische Reihe, elektrisches Feld & Feldlinien, Feldstärke, Kondensator, Halbleiter & Dotierung, Transistor, Magnetismus, Lorentzkraft, Elektromagnet, Elektromotor – plus Quiz und Spickzettel.

## Nutzen
- Datei einfach im Browser öffnen (Doppelklick) – funktioniert offline, keine Installation.
- Navigation mit „Weiter →“ / „← Zurück“ oder Pfeiltasten.
- Zum Hosten genügt jeder Static-Host (z. B. GitHub Pages: Repo → Settings → Pages → Branch `main`, Ordner `/` – dann ist die Seite unter `https://<user>.github.io/nawi2/nawi-lernseite.html` erreichbar).
